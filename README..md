# Reselling Profit Calculator

A simple open-source web calculator for resellers and small online businesses.

## Features

- Calculate product profit
- Calculate loss
- Calculate profit percentage
- Include additional expenses
- Simple and beginner-friendly interface
- Works directly in a web browser

## How to Use

1. Enter the product buying price.
2. Enter the selling price.
3. Enter any additional expenses.
4. Click "Calculate Profit".
5. The calculator will show the profit or loss and percentage.

## Example

Buying Price: ₹100  
Selling Price: ₹200  
Other Expenses: ₹20  

Total Cost: ₹120  
Profit: ₹80

## Technology

- HTML
- CSS
- JavaScript

## Purpose

This project was created as a simple tool to help resellers understand their product profit before selling.
